## eSIM 到底是什么，装的时候容易卡在哪

eSIM 的全称是 Embedded SIM，是一张内置在设备里的数字 SIM，不是可插拔的芯片。服务信息加密存在手机里，通过设置更新，激活后连网、打电话、发短信、用流量的方式和实体卡完全一样。换手机时不用抠卡针，在 Wi-Fi 下下载并激活就行。

AT&T 的科普页把优缺点列得很实在。好处是开通快、不用去门店或等邮寄、手机丢了可以远程关掉线路、部分机型能同时存多个配置文件，把工作号和私人号放在一台机器上。麻烦的地方有三条：不是所有手机都支持；把服务转移到新设备有时比换实体卡步骤更多；下载和激活必须联网，没有 Wi-Fi 也没蜂窝数据就会卡住。

USA eSIM 的安装方式有三种：扫二维码、App 内一键安装、手动输入激活信息。手机在安装那一步必须联网，所以官方建议出发前在家里的 Wi-Fi 下装好，落地之后再启用线路。这个顺序很关键，机场 Wi-Fi 掉线、漫游还没开通的时候装不上，人就傻在到达大厅了。

## 常见问题

**国内能提前激活吗？**
旅行 eSIM 是“提前安装、落地启用”，出发前在 Wi-Fi 下装好，落地打开数据漫游，安装这个动作不消耗套餐天数。保号卡在国内激活是另一回事，需要美国出口 IP 和 Wi-Fi Calling，属于社区变通，有风控风险。

**天数从哪天开始算？**
第一次在美国连上网络那一刻，不是付款日，也不是安装日。

**原来的卡还能用吗？**
能。国内 SIM 留在手机里当主卡，电话、短信、微信照常，只有数据走 eSIM。落地后记得把主卡的数据漫游关掉。

**一个手机能装几个 eSIM？**
现在的机型可以存多个配置文件，同一时间启用一个上网，下次去别的国家再切换。一个账号里也能同时持有多个 eSIM。

**收不到银行验证码怎么办？**
先确认买的是哪一类套餐。纯流量套餐不带美国号码，收不了以短信形式发送的验证码；要收码就得选语音套餐。号码是回收号的情况也会导致部分服务验证失败，这在小运营商里并不罕见。

**流量用完了要重新装吗？**
不用。有效期内直接在 App 里加购，同一张 eSIM 继续用；过期之后无法加购，得重新买一张。

**能退款吗？**
未安装、未使用数据，购买后 15 天内可申请全额退款，通过 App 内的支持页面或客服邮箱提出，退款原路返回支付方式。
